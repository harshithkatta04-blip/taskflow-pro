# TaskFlow Pro
TaskFlow Pro is a full-stack MERN-based task management application designed to help users efficiently manage their daily tasks with secure authentication and a responsive user experience.
## Live Application
Frontend: https://taskflow-3trb7pnou-harshith-katta-s-projects.vercel.app/  
Backend API: https://taskflow-backend-met7.onrender.com/
## Key Features
- Secure user authentication using JWT
- User registration and login system
- Create, update, delete, and manage tasks
- Protected routes for authenticated users
- RESTful API integration between frontend and backend
- Responsive and user-friendly interface
## Tech Stack
Frontend:
- React (Vite)
- Axios
- CSS
Backend:
- Node.js
- Express.js
- JWT Authentication
Database:
- MongoDB Atlas
Deployment:
- Vercel (Frontend)
- Render (Backend)
## Architecture
Client (React) ↔ REST API (Express) ↔ MongoDB Atlas
